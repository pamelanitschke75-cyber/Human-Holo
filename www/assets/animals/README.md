# Human Holo – öffentliche Tierprofilbilder

Diese fünf verkleinerten Profilbilder gehören zu den Human-Holo-Tierprofilen
von Salt, Peps, Tina, Gurke und Möhrchen.

Pamela Christina Nitschke hat am 13.09.2026 ausdrücklich bestätigt, dass diese
Tierbilder öffentlich in das Human-Holo-Repository und in den Android-Build
aufgenommen werden dürfen.

Tinas Profilbild wurde mit einem OpenAI-Bildwerkzeug ausschließlich so
bearbeitet, dass die zuvor mit abgebildete Tochter vollständig entfernt ist.
Tina bleibt das einzige Lebewesen im veröffentlichten Bild.

`human-holo-animal-core.mjs` und `human-holo-animal-holos.mjs`.

weiterhin privat sowie owner- und sprechergebunden gespeichert.
